Community Issue Reporting System

A simple way for residents to report local problems and for the Office to resolve them — with everything tracked in one place.

Project home page · proposal and source code linked below

What it does

Residents report a local issue — a broken streetlight, a pothole, an overflowing drain, a burst water pipe — with a category, a location and an optional photo, and get a tracking reference. Office staff see every report in one list, triage it, and assign it to a field worker who moves it from New to Resolved. The resident is notified as the status changes, and a supervisor sees a dashboard of open issues, issues by category, and average resolution time.

Who uses it

  • Residents — report an issue and follow its progress without chasing anyone.
  • Field staff — see assigned issues and update or resolve them.
  • Supervisor / Admin — triage, assign, and monitor issues on a dashboard.

Client (course requirement — imaginary): the public-works office of a city / commune, referred to as the Office.

How it is built

A web application in PHP with a MySQL database, runnable locally with XAMPP. The source code, database schema, and design diagrams live in the repository.
